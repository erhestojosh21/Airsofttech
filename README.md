**AirsoftTech: A Web-Based E-Commerce Platform with 3D Modeled Airsoft Attachments for EdGi Custom Works**

AirsoftTech is a web-based e-commerce platform developed as a **Bachelor of Science in Information Technology (BSIT) Capstone Project** at **STI College Novaliches**.  
The system enhances the online shopping experience for airsoft enthusiasts by integrating **interactive 3D product visualization**, secure transactions, and comprehensive admin management tools. It is designed specifically for **EdGi Custom Works** to support pre-order–based sales, improve customer confidence, and reduce product returns.

---

## Project Overview

Traditional e-commerce platforms rely on static images and text descriptions, which often lead to customer uncertainty and high return rates. AirsoftTech addresses this issue by allowing users to **view, rotate, and inspect airsoft attachments in 3D** before purchasing.

The platform supports customers, admins, managers, and airsoft staff through role-based access, ensuring secure and efficient operations.

## Objectives

### General Objective
- To develop an innovative e-commerce platform that improves the airsoft shopping experience through interactive 3D visualization.

### Specific Objectives
- Implement 3D modeled airsoft attachments for accurate product evaluation  
- Reduce product return rates through detailed product presentation  
- Provide a user-friendly platform with live chat and FAQ support  
- Increase sales conversion and customer loyalty  
- Ensure secure transactions and data protection  

---

## System Features

### Customer Features
- User registration and secure login (OTP, CAPTCHA)  
- Browse airsoft products with detailed descriptions  
- Interactive 3D product visualization (desktop/tablet)  
- Shopping cart and secure checkout  
- Product reviews and ratings  
- Pre-order system (manual admin approval)  
- Multiple address management  
- Live chat and FAQ support  
- Order history and tracking  

### Admin & Staff Features
- Role-based access control (Admin, Manager, Staff)  
- Product and category management  
- User account management (restrict, ban, logs)  
- Order and pre-order management  
- Employee account management  
- Audit trail and activity logs  
- Sales reports and dashboard analytics  

---

## Security Features

- JSON Web Token (JWT) authentication  
- One-Time Password (OTP) verification  
- Password hashing (bcrypt)  
- Encrypted sensitive data (AES-256)  
- Google reCAPTCHA  
- Rate limiting for login and OTP requests  
- Role-Based Access Control (RBAC)  
- Input validation and sanitization  
- Secure HTTP headers (Helmet)  
- Activity logging and audit trails

## Scope & Limitations

- Pre-order–based system only  
- No real-time courier tracking  
- PayPal as primary payment gateway  
- No automated discounts or bulk ordering  
- 3D models not supported on mobile devices  
- Platform focuses exclusively on **EdGi Custom Works** products
